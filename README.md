## News App
build using Kotlin Multiplatform architecture for Android and iOS platform.

[API Doc ↗️](https://newsapi.org/docs)

## Features
- Home Page with endless scroll
- News by category section
- Detail redirect to web view url sources
- Search sortBy popular articles

## Tools
- **Kotlin Multiplatform**
- **Compose Ui (Android/iOS)**
- **Ktor Network Library**
- **Koin Dependency Injection**
- **MVVM Pattern**
- **Turbine for Unit Testing**
